# Torah Reading Site

Bilingual Hebrew/English Torah reading website foundation for the Nissim Shaked YouTube channel.

## Development

```bash
npm run dev
```

Primary locale: Hebrew (`/he`)

Secondary locale: English (`/en`)

## YouTube Metadata Import

The importer uses YouTube Data API v3 and stores metadata only. It does not
download videos or save media files locally.

1. Create an API key:
   - Open [Google Cloud Console](https://console.cloud.google.com/).
   - Create or select a project.
   - Enable **YouTube Data API v3**.
   - Create an API key under **APIs & Services > Credentials**.

2. Add the key to your shell:

```bash
YOUTUBE_API_KEY=your_api_key_here
```

PowerShell:

```powershell
$env:YOUTUBE_API_KEY="your_api_key_here"
```

3. Run the import:

```bash
npm run import:youtube
```

For routine refreshes after the first import, run:

```bash
npm run update:youtube
```

The script resolves `@nissimshaked`, reads the uploads playlist, fetches all
public videos with pagination, and saves embed-ready metadata to:

```txt
data/youtube-videos.json
```

Manual corrections belong in:

```txt
data/manual-overrides.json
```

Overrides are applied after automatic classification and support `category`,
`subcategory`, localized titles, localized slugs, `parashaSlug`, `tags`,
`nusach`, `displayOrder`, `featured`, and `hidden`.

Embeds should use `https://www.youtube.com/embed/{videoId}` without autoplay.

## Refreshing YouTube Content

Use `npm run update:youtube` for ongoing updates. It re-fetches channel metadata,
updates existing videos by `videoId`, appends new videos, avoids duplicates, and
keeps manual curation in `data/manual-overrides.json` separate.

Suggested cadence: daily while the channel is active, or weekly for lighter
maintenance.

After refreshing:

```bash
npm run validate:content
npm run build
git add data/youtube-videos.json data/manual-overrides.json
git commit -m "Update YouTube metadata"
git push
```

Automation options:

- Vercel Cron: create a scheduled route or job that runs daily and triggers the
  metadata update workflow in your deployment process.
- GitHub Actions: add a scheduled workflow with `cron: "0 3 * * *"` that runs
  `npm install`, `npm run update:youtube`, `npm run validate:content`, and opens
  a PR with changed metadata.

## Manual Curation

Do not edit `data/youtube-videos.json` by hand. It is generated by the YouTube
importer and may be replaced. Put editorial corrections in
`data/manual-overrides.json`; the website applies them at read time.

Example:

```json
{
  "videos": {
    "YOUTUBE_VIDEO_ID": {
      "category": "parashat-hashavua",
      "subcategory": "aliyah",
      "title": {
        "he": "קריאת פרשת במדבר",
        "en": "Parashat Bamidbar Reading"
      },
      "slug": {
        "he": "קריאת-פרשת-במדבר",
        "en": "parashat-bamidbar-reading"
      },
      "parashaSlug": "bamidbar",
      "tags": ["torah-reading", "bamidbar"],
      "nusach": "sephardic-yerushalmi",
      "displayOrder": 10,
      "featured": true,
      "hidden": false
    }
  }
}
```

Common edits:

- Correct titles: set `title.he` and/or `title.en`.
- Assign a video to a parasha: set `parashaSlug`, for example `"bamidbar"`.
- Hide a video: set `"hidden": true`.
- Feature a video on the homepage: set `"featured": true` and optionally `displayOrder`.

Validate curation:

```bash
npm run validate:content
```
